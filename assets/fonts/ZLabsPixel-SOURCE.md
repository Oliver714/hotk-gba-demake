# Z Labs Pixel 12px M CN

User-supplied original: `Z+工坊像素黑体+12px/ZLabsPixel_12px_M_CN.ttf`.
An unchanged copy is retained here so builds do not depend on the review folder.

- Family: Z Labs Pixel 12px M CN; style: Regular.

Body/battle text uses native12px monochrome glyphs. Existing16px heading slots
center the12px glyph, without fractional scaling. The title logo uses an exact
2x enlargement. Existing cell widths and navigation layouts are unchanged.
Only glyph masks enter the ROM; no runtime rasterisation occurs.

Source scans include disabled legacy text containing rare mojibake characters.
Unsupported characters in those tables use Source Han Mono SC as a fallback;
see `SourceHanMono-SOURCE.md` and `SourceHanMono-LICENSE.md`. Active UI strings
and imported game names are checked separately for primary-font coverage.
