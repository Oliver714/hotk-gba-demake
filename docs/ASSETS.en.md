# Asset maintenance

[简体中文](ASSETS.md) · [English README](../README.en.md)

Normal builds use the checked-in `generated/` resources and do not regenerate assets. Different optional asset-tool environments should therefore not change the ROM unless regeneration is requested.

## Available converters

Install the optional dependencies with `python3 -m pip install -r requirements-assets.txt`. The pinned Pillow 9.0.1 setup was validated with Python 3.10; use a virtual environment. These packages are not needed for normal builds.

```bash
python3 tools/regenerate_assets.py battle
python3 tools/regenerate_assets.py effects
python3 tools/regenerate_assets.py ui
python3 tools/regenerate_assets.py font
```

- `battle`: updates packed frame compression, arrays, and palettes from the v14 battle atlas, v4 walking sheet, and v5 cavalry sheet in `assets/battle/`.
- `effects`: regenerates standalone effect images, projectile effects, and available row-based beam arrays and palettes. Historical `magic_*` data tables are not regenerated by this entry point.
- `ui`: rebuilds UI tiles, glyphs, and palettes from the theme JSON and title background.
- `font`: scans current source and data strings alongside retained historical glyph sets. It uses ZLabs 12px, with Source Han Mono for missing characters. Regeneration may change glyph tables, layout, and ROM checksums.

Regenerate only the required group, review the `generated/` diff, run tests, rebuild, and inspect the result in an emulator. Changes to shared palettes must also preserve color consistency in historical generated resources.

## Replacing music

The two current background tracks are extracted from *Romance of the Three Kingdoms VI*: *Zhu Lu Tian Xia* (逐鹿天下) and *Feng Huo Bian Ye* (烽火遍野). The repository contains compressed converted data, not the original MP3 files. To replace them, put music you have permission to use at the exact paths `audio_design/主游戏.mp3` and `audio_design/战斗.mp3`, install system ffmpeg, then run:

```bash
python3 tools/regenerate_assets.py music
```

This overwrites the checked-in ADPCM and metadata and creates an ignored WAV preview. Record the replacement's provenance and license, then commit the generated results. Audio compression does not establish rights to the music. See the [music input guide](../audio_design/README.en.md).

Character portraits are extracted from the original *Heroes of the Three Kingdoms 1*. ZLabs Pixel 12px and the Source Han Mono fallback have separate licenses. Original fonts, source notes, and OFL license texts are in `assets/fonts/`.

## Resources available only as converted data

Maps, portraits, some effects, and game data do not have their full original inputs in this repository. The retained converted tables can be maintained directly; newly written converters can also be added. The project does not provide an entry point for reimporting these resources from external original-game files.

See the [provenance inventory](ASSET_PROVENANCE.en.md) for asset rights and redistribution status.
