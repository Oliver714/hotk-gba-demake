# Asset provenance and licensing status

[简体中文](ASSET_PROVENANCE.md) · [English README](../README.en.md)

This inventory distinguishes technical buildability from confirmed redistribution rights. GPL-3.0-only covers original project code; it does not replace authorization for third-party assets.

| Files | Provenance and status |
|---|---|
| `assets/fonts/` | ZLabs Pixel and Adobe Source Han Mono. Original font files and OFL licenses are retained for optional glyph regeneration. |
| `assets/ui/silk-title-v1.png` | Historical records identify an image-generation tool as the source. The prompt is retained in the adjacent source note. |
| Current atlases in `assets/battle/` | Historical generated images with later edits. Walking and cavalry source notes are retained; authorship and permission records for the main atlas remain incomplete. |
| `assets/effects/battle-effects-v1.png` | Historical generated effects image. The file is retained, but its full provenance and rights record still needs verification by the maintainer. |
| `generated/font_data.cpp`, `generated/silk_ui_data.cpp` | Generated by repository and historical converters. Font-derived portions remain subject to OFL; other content follows its respective provenance. |
| `generated/face_data.cpp` | Portraits extracted from the original *Heroes of the Three Kingdoms 1*. They are not project-owned GPL assets. |
| `generated/terrain_map.cpp`, `generated/menu_skin_data.cpp`, some `magic_*.cpp`, and similar resources | Historical converted resources or data generated using original-game references. The original source game assets are not included, and evidence of redistribution permission for these generated tables has not been provided. |
| `generated/game_data.cpp` | Project-organized data tables containing historical names and reference data. Specific sources and permitted redistribution scope still need verification. |
| `generated/music_*.adpcm`, `generated/music_adpcm.cpp` | Two tracks extracted from *Romance of the Three Kingdoms VI*: *Zhu Lu Tian Xia* (逐鹿天下) and *Feng Huo Bian Ye* (烽火遍野), as identified by the maintainer. No evidence of music redistribution permission has been obtained; they must not be represented as GPL music. Original MP3 files are not included. Replace the tracks with `tools/regenerate_assets.py music`. |

Before distribution, verify the rights for each asset or replace it with an independently created asset under a clear license. No documentation establishing authorization for original-game assets is included in this project.

The repository does not include the original game, `SANGO.PAK`, or related extraction tools. The demake is based on the original *Heroes of the Three Kingdoms 1*; GBA gameplay may differ.
